# Visual Identity

【待人工審核】本目錄為視覺內容生成 Bot 依主 PMO 授權產出的視覺素材，僅供內部審核，未經主 PMO 核准不得對外使用。

## batch1（2026-11-10，Asia/Taipei）
依據：主 PMO 提供的「wonderland.center 視覺識別系統」提示詞（第一批：Logo 與 Hero 主視覺）。

| 檔案 | 用途 |
|---|---|
| `batch1/logo-light.png` | 主 Logo 淺色背景版 |
| `batch1/logo-dark.png` | 主 Logo 深色背景版 |
| `batch1/logo-icon.png` | Logo 圖標版（方形） |
| `batch1/hero.png` | Hero 主視覺（16:9，1280×720） |
| `batch1/log.md` | 生成紀錄（提示詞、參數、時間、費用） |

審核注意：Logo 三張偏向品牌看板／網站樣機而非獨立定稿；含模型自行加入的英文文案；Hero 解析度未達 1920×1080；配色、Logo 形式與本 repo 既有 CIS（水月青、澄心金、水月圓環）差異明顯。
